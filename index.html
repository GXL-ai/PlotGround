PlotGround

Grounding Plot Digitization in Real Scientific Figures and Their Source Data

How accurately can frontier multimodal models read numbers off real scientific figures?

PlotGround is an automated pipeline for building plot digitization benchmarks from real scientific figures and their source data. With it we construct PlotGround-1k, 1,119 human-verified questions from 1,066 bioRxiv preprints, and evaluate 16 models on it.

The PlotGround Pipeline

Instead of rendering synthetic charts from data, PlotGround starts from real figures and works backward to ground each plotted value in its source data.

01

Mapping

Bind each figure to candidate supplementary tables using direct evidence (explicit references in text) or indirect evidence (figure descriptions matching table contents).

02

Grounding

Keep only panels whose values can be recovered with simple operations such as selection, aggregation, ratios, or log transforms, and record a reconstruction recipe anchored to literal evidence.

03

Synthesis

Execute the recipe, sanity-check the recomputed values, and write at most two questions per figure using only figure-visible labels.

Benchmark Examples

Models receive the complete multi-panel figure. Each question names its target only with identifiers visible in the figure; the answer is recomputed from the deposited source table.

Leaderboard

Each model sees the full figure and a question targeting one plotted value, and answers from the figure alone. Accuracy is the share of predictions within a relative-error tolerance of the source-grounded reference value.

Figure–Data Discrepancies

During human verification we found 8 figures whose plotted values disagree with the values reconstructed from their own deposited source data. Our review found no recipe error that explains the gap, so these candidates were excluded from PlotGround-1k.
